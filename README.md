# rusport.org — сайт Русского спортивного общества

Сайт (HTML + CSS + JS) + бэкенд на Django: база новостей, админка, приём заявок. Стиль по образцу rgo.ru, цвета из логотипа РСО.

## Страницы

| Файл | Что это |
|---|---|
| `index.html` | Главная: фото-слайдер → проекты → об обществе → вступить → новости → две идеи → участникам → партнёры → манифест |
| `project.html?id=…` | Страница проекта (community, b2b, analytics, sporttech, investments, media, charity, academy, events) |
| `audience.html?id=…` | Что получает аудитория (clubs, managers, brands, athletes) |
| `news.html`, `post.html?id=…` | Лента новостей и отдельная новость |
| `join.html` | Анкета на вступление: физлицо / юрлицо |
| `/admin/` | **Админка** (Django): новости, заявки, подписчики |
| `privacy.html` | Политика ПДн — черновик, финальный текст от юристов |

## Бэкенд (Django, папка `backend/`)

Django отдаёт сайт, хранит базу и даёт админку. Код бэкенда хранится в отдельном **приватном** репозитории `shtankogoat/rusport-backend` — клонируйте его в папку `backend/` рядом с сайтом. На GitHub Pages сайт работает без бэкенда: новости и формы включатся после запуска на сервере.

- **Запуск у себя:** двойной клик по `backend/run.bat` → сайт на http://127.0.0.1:8000/, админка на http://127.0.0.1:8000/admin/.
- **Админка `/admin/`** (вход по логину и паролю):
  - **Новости** — заголовок, дата, рубрика, анонс, обложка, галочка «Опубликовано» и блоки: текст, подзаголовок, цитата, фото, видео (YouTube, VK Видео, Rutube, .mp4). Порядок блоков — поле «Порядок». Фото сжимаются автоматически.
  - **Заявки на вступление** — всё из анкеты `join.html`, статусы (новая → на рассмотрении → одобрена → оплачена), заметки команды, выгрузка в Excel.
  - **Подписчики рассылки** — email из формы в подвале, выгрузка в Excel.
  - **Пользователи** — добавьте редакторов (галочка «Статус персонала» + права на «Новости»).
- **API:** `GET /api/news/`, `GET /api/news/<slug>/`, `POST /api/forms/`.
- База — SQLite (`backend/db.sqlite3`), фото — `backend/media/`. Обе папки **не попадают в git**; на сервере их нужно бэкапить.
- Наружу отдаются только страницы `*.html` и папка `assets/` — код, база и внутренние файлы закрыты.

### Запуск на сервере (кратко)

```
pip install -r requirements.txt
export DJANGO_DEBUG=0 DJANGO_SECRET_KEY=<длинный случайный ключ> \
       DJANGO_ALLOWED_HOSTS=rusport.org,www.rusport.org \
       DJANGO_CSRF_TRUSTED_ORIGINS=https://rusport.org,https://www.rusport.org
python manage.py migrate && python manage.py collectstatic --noinput
python manage.py createsuperuser
gunicorn rso.wsgi -b 127.0.0.1:8000 -w 2      # за nginx с HTTPS
```

GitHub Pages Django не запускает: без сервера сайт открывается, но новости и формы не работают.

## Что подключить перед запуском

1. **Сервер** для Django (например, VPS) + домен rusport.org + HTTPS.
2. **Эквайринг** — сейчас «анкета → одобрение в админке → ссылка на оплату по email»; онлайн-оплату (ЮKassa и т. п.) можно добавить в бэкенд.
3. **Уведомления о новых заявках** (email или Telegram-бот) — по желанию.
4. **Логотипы партнёров** — `index.html`, секция `#partners`.
