# rusport.org — сайт Русского спортивного общества

Статический сайт (HTML + CSS + JS), без сервера и сборки. Работает на GitHub Pages или любом статическом хостинге. Стиль по образцу rgo.ru, цвета из логотипа РСО. Язык: РУ / EN.

## Страницы

| Файл | Что это |
|---|---|
| `index.html` | Главная: слайдер → проекты → об обществе → вступить (соцсети) → две идеи → что получает индустрия → партнёры → манифест |
| `join.html` | Анкета на вступление: вкладки физлицо / юрлицо со встроенными Google Формами |
| `privacy.html` | Политика ПДн — черновик, финальный текст от юристов |

## Где что менять

| Что | Где |
|---|---|
| Проекты и блок «Что получает индустрия» | `assets/js/data.js` → `RSO_PROJECTS`, `RSO_AUDIENCES` |
| Ссылки на Telegram, MAX, ВКонтакте | `assets/js/data.js` → `RSO_SOCIAL` |
| Ссылки на Google Формы | `assets/js/data.js` → `RSO_FORMS` (формы создаёт `tools/google_forms.gs`) |
| Английские переводы | `assets/js/i18n.js` → `EN`: каждой русской фразе на сайте — английская |
| Слайдер, тексты главной, партнёры | `index.html` |
| Шапка и подвал (общие для всех страниц) | `assets/js/main.js` → `renderHeader`, `renderFooter` |

После правки CSS/JS увеличьте версию `?v=…` в ссылках на файлы во всех трёх HTML-страницах — иначе телефоны покажут старую версию из кэша.

## Фотографии

Файлы в `assets/img/photos/`, сайт подхватывает их по имени. Если фото нет — на его месте заглушка с именем файла.

| Файл | Где | Размер |
|---|---|---|
| `hero-premium.jpg`, `hero-unite.jpg`, `hero-nation.jpg` | Слайдер: премия · «Объединяем…» · «Здоровая нация…» | 1920×1080 |
| `project-<id>.jpg` (9 шт.) | Карточки «Наши проекты» | 900×675 |
| `audience-<id>.jpg` (4 шт.) | «Что получает индустрия» | 900×675 |
| `idea-state.jpg`, `idea-life.jpg` | «Две идеи» | 1200×900 |
| `dialog.jpg` | Фон блока «Об обществе» | 1920×1080 |
| `join.jpg` | Шапка страницы «Вступить» | 1920×600 |

## Что ещё нужно

1. **Логотипы партнёров** — `index.html`, секция `#partners`.
2. **Фото для второго слайда** — `hero-unite.jpg`.
3. **Политика конфиденциальности** — финальный текст; учесть, что анкеты хранятся в Google Формах (152-ФЗ, локализация данных).
